# 複数の注釈の整列・等間隔配置

## 決定

| 項目 | 決定 |
|---|---|
| 置き場所 | Core の `Arrange`(`Sources/KakiireCore/Edit/Alignment.swift`)。結果は注釈ごとの `.move` の列で、`EditOperation` は増やさない。まとめて `apply` するので Undo 1回分 |
| 揃える基準の外形 | `Annotation.frame`:形そのものの外形。矩形・楕円・効果・画像は `rect`、矢印・線は2点を囲む矩形、文字は `TextLayout.bounds`、スタンプは円、ペン・ハイライターは点を囲む矩形。線の太さ・矢じりの余白・画像の縁や影は含めない(`bounds` は再描画用で余白が大きく、矢印は `width * 2 + 縁` も外に広がるため、揃えてもずれて見える) |
| 揃える先 | 選んだ注釈の `frame` を合わせた範囲の辺・中心。1つだけ選んだときは何もしない |
| 等間隔 | 3つ以上。位置の順に並べ、両端の2つを固定し、隣どうしの辺の間の隙間を等しくする(中心の間隔ではない) |
| ロック | 動かさないが、揃える範囲には含める(ロックした注釈に揃えられる) |
| 非表示 | 対象外 |
| UI | 「編集 › 整列」のサブメニューだけ。ショートカットは付けない(⌥⌘+/- は文字サイズ、矢印は少しずつ移動で使っている)。ツールバーはツールとスタイルの状態を出す場所なので置かない |

## 見直す条件

- 1つだけ選んだときに画像(切り抜き範囲)に揃えたくなったとき
- 太い線の図形どうしで「線の外側」で揃えたいという声が出たとき
