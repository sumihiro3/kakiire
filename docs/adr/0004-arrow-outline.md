# 矢印の白い縁取り(袋文字)

## 決定

| 項目 | 決定 |
|---|---|
| 持ち方 | `ArrowSpec.outline`(既定 false)。文字の袋文字(既定 true)とは別の項目にし、App の `DrawingStyle` でも `arrowOutline` として別に持つ |
| 保存 | `style.outline: true`。縁なしは書かない。`formatVersion` は 1 のまま |
| 縁の幅 | 矢印の外へ `max(2, 太さ × 0.15)` px(細い 12 で 2、ふつう 20 で 3、太い 32 で約 4.8)。描画・当たり判定・描画範囲は `ArrowSpec.outlineBand` だけを使う |
| 縁の色 | 白。白い矢印のときだけ黒(文字の袋文字と同じ決まり) |
| 描き方 | 縁を先に全部描き、その上に矢印を描く。先細りは塗りの形を `2 × 縁の幅` の線でなぞる。開いた矢じり・破線は線幅を `2 × 縁の幅` 太らせる。破線の長さは芯の線幅で決め、縁と芯の切れ目をそろえる |
| 切り替え | 太さボタンのメニューの最後に「白い縁取り」。矢印ツールのときか、矢印を選んでいるときだけ出す(線の種類ボタンと同じ決め方) |

## 理由

- 赤い矢印は、赤や暗い部分の多い画像で埋もれる。縁を付けると背景の色に関係なく形が読める
- 既定を縁なしにして書かないので、これまでの文書の見た目も中身も変わらない。逆に古い版の Kakiire で開いて保存すると縁が消えるが、実害は見た目が元に戻るだけなので版は上げない(ADR 0002 の dash と同じ)
- 縁の幅を1か所にまとめたのは、描画と当たり判定・再描画範囲がずれると、縁の外側をつかめなかったり描き残しが出たりするため
- アプリのアイコン(`scripts/make-icon.swift`)の矢印は、太さ 16 に対して白線 3.5(外へ約 1.75 = 0.11 倍)と濃い外縁。アプリより少し細いが、アイコンは濃い外縁と合わせての演出なので、そのままにする
