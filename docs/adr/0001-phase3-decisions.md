
# Kakiire フェーズ3の方針:リサイズ時の線幅、レイヤーパネル、Skitch 取り込み、描画グループ

## 決定

| 項目 | 決定 |
|---|---|
| リサイズ時の線幅 | **画像と一緒に縮む**。`outputScale` は書き出し画像全体を縮める倍率で、線・文字の太さも同じ比率で細くなる |
| レイヤーパネル | ウインドウ**右のサイドバー**。表示メニュー(⌥⌘L)で開閉する |
| 旧 Skitch 画像の取り込み | **やらない**。普通の PNG として開ける(注釈は焼き込まれた絵として)。未決事項を閉じる |
| 描画の順序 | 「画像オーバーレイ → 効果(モザイク・ぼかし)→ ハイライター → 図形」の4グループ。並べ替えはグループの中だけ |
| 回転・反転で注釈が付いていく方法 | 2点で決まるもの・矩形・ペンの点列は座標を変換する。画像オーバーレイは元画像と同じく向きを持ち、中身ごと回す。テキスト・スタンプは読めるよう正立のまま、外形の中心だけ移す |

## 理由

- 線幅:画面の見た目と書き出しが比率で一致する(WYSIWYG)。Skitch も画像ごと縮む。今の Renderer がそのまま満たすのでコード変更もない。太さを保つ方式は、縮小後に矢印が相対的に太くなり、画面で見たものと違う絵になる
- レイヤーパネル:ツールバーが左なので左右に分かれ、キャンバスを挟む。ウインドウごとの対応が明確
- Skitch 取り込み:埋め込みデータの形式が非公開で調査工数が大きい。手元の旧画像は PNG として開ければ足りる
- 画像オーバーレイを中身ごと回す理由:正立のまま位置だけ移すと、上に掛けたモザイクとずれて伏せた内容が見えてしまう(実機で発見)。90° 単位なので無劣化
- 描画グループ:仕様で、モザイクは元画像**と画像オーバーレイ**に対して計算する(貼った画像も伏せられる)。ハイライターは乗算合成で、下の画像・効果が透けて見える必要があるため図形より下に置く
