# 切り抜きの px 指定、画像オーバーレイの枠線と影、スタンプの種類(0.4.0)

## 決定

| 項目 | 決定 |
|---|---|
| 切り抜きの px 指定 | 「画像 › 切り抜きの範囲を指定…」(⌥⌘K)と、切り抜きツールの案内のクリックでシートを出す。左・上・幅・高さ(px)と「縦横比を固定」。OK で切り抜きツールの範囲にし、確定は Return(ガイドで確かめてから確定する) |
| 範囲の整え方 | `CropMath.fit`:整数の px に丸め、はみ出した分は大きさを保ったまま中へずらす。画像より大きければ画像の大きさで止める。最小 1px |
| 画像の枠線 | `ImageSpec.border`(色・幅・位置)。幅は 細 2 / ふつう 4 / 太 8 pt × pixelScale。位置は「内側」(既定。画像の縁に重ね、外形は変えない)か「外側」(画像を欠かさず囲む。描画範囲は枠の幅だけ広がるが、当たり判定とつまみは画像の矩形のまま)。太さボタンのメニューで選ぶ |
| 画像の影 | `ImageSpec.shadow`(ぼかしの半径 px、0 で影なし)。黒・不透明度 0.35・下へ半径の 0.3 倍。画像そのものから落とす(透明部分のある画像でも形に沿う)。描画範囲は影の分だけ広げるが、当たり判定は画像の矩形のまま |
| 枠線・影の描き方 | `Renderer.drawOverlay` だけで描き、画面・書き出し・モザイクの合成で共有する。効果のキャッシュのキーにも枠線と影を入れる |
| 枠線・影の操作 | 画像を選ぶと太さボタンが「枠線なし/細/ふつう/太」と「影を付ける」になる。色ボタンは枠のある画像の枠の色だけを変える(色を選んだだけで枠が付くと驚くため)。新しく挿入する画像は、最後に選んだ枠線・影を使う |
| スタンプの種類 | `StampSpec.kind`:数字(既定)・英字・記号(✓ ✗ ? !)・絵文字(👍 👎 ⚠️ ❤️ ⭐️ 🔥 👀 💡)。英字は 1→A … 26→Z、27→AA |
| 番号の進み方 | 数字と英字は別々に数える(同じ種類の最大 + 1)。記号と絵文字は進まない |
| スタンプの見た目 | 数字・英字・記号は色の丸に白い文字。絵文字は丸を描かず、色は効かない |
| 種類の選び方 | スタンプツールか、スタンプだけを選んでいるときに、線の種類ボタンの位置に「スタンプの種類」ボタンを出す。スタンプツールのまま種類を変えても、置いた直後で選ばれているスタンプは変えない(次に置くものを選ぶ操作のため)。既存のスタンプの種類は、選択ツールで選んでから変える |
| 保存 | 既定(枠なし・影なし・数字)は書かない。枠線は `style.borderColor` / `borderWidth` と、外側のときだけ `borderPosition: "outside"`、影は `style.shadow`、スタンプは `style.kind`("letter" / "symbol" / "emoji")と `symbol`。`formatVersion` は 1 のまま |

## 理由

- 切り抜きを数値で決めたいのは、ブログや資料で画像の大きさをそろえたいとき。すぐ確定せずガイドに映すのは、位置を目で確かめてから確定できるようにするため
- 枠線を内側に描くのは、外形(つまみ・当たり判定・スナップ)を変えないため。影を当たり判定に入れないのは、影の上をクリックして画像がつかめると、下の注釈を選びにくくなるため
- 枠線・影をモザイクの合成に入れないと、モザイクの下で枠だけがくっきり残り、見た目がずれる
- 保存の形は ADR 0002・0004 と同じ方針で、既定値を書かないので、これまでの文書の中身は変わらない。古い版の Kakiire で開くと、枠線と影は消え、英字のスタンプは数字に、記号・絵文字のスタンプは 1 に見える。再保存するとその形になるが、注釈そのものは失われないので版は上げない
