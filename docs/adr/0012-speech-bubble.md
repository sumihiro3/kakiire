# 吹き出し

## 決定

| 項目 | 決定 |
|---|---|
| 種類 | 新しい注釈の種類 `bubble`(`BubbleSpec`)。形は角丸の四角(`rounded`、既定)・楕円(`ellipse`)・雲(`cloud`)・ギザギザ(`shout`)の4つ |
| 大きさ | 文字に合わせて決まる(折り返さない。改行は Return)。四隅のつまみは、テキストと同じく反対の隅を固定して文字の大きさを変える |
| 色 | 選んだ色で塗り、文字は白。白で塗ったときだけ文字と縁を黒にする(スタンプ・矢印の縁取りと同じ決まり) |
| しっぽ | 先の位置 `tail` を絶対座標で持つ。つまみ(`Handle.tail`)で先だけ動かせる。先が本体の中にあるときは描かない。雲は小さくなる丸を3つ並べる |
| 本体の位置 | `origin` は中の文字の箱の左上(`TextSpec.origin` と同じ意味)。本体はその箱を囲むように作る |
| 形の計算 | Core の `BubbleLayout` だけが持つ。描画・当たり判定・外形・整列・CLI の範囲はすべてここの輪郭を使う。雲の山とギザギザのトゲは、楕円の周を同じ長さで区切って並べる(角度で区切ると横長の楕円の両端で詰まる) |
| 回転・反転 | 本体は正立のまま中心だけを移し(テキストと同じ)、しっぽの先は画像と一緒に動かす |
| 整列 | 本体の外形(しっぽを含めない)で揃える |
| 作り方 | 吹き出しの道具(キー `S`)で、指したい所から置きたい所へドラッグする。クリックだけなら押した所を本体の中心にし、しっぽを左下に出す。置いたらすぐ文字の入力になり、空のまま確定したら作らない |
| 文字の編集 | テキストと同じ入力欄(`TextEditing`)を使う。吹き出しは入力欄の背景を透明にし、下に吹き出しを打った文字に合わせて描く(文字だけ描かない) |
| 保存の形 | `{"type":"bubble","geometry":{"origin","tail"},"style":{"color","fontSize","bold"?,"shape"?},"text"}`。既定(太字・角丸)は書かない |
| 互換 | `formatVersion` は 1 のまま(種類を足すのは互換を壊さない)。古い版では知らない種類として残り、描かれず選べないが、保存し直しても消えない |
| CLI / MCP | `bubble` を受け付ける。描いた範囲に文字の箱 `glyphs` も返す |

## 作らなかったもの

- 枠の大きさを決めて文字を折り返す方式。文字の配置に新しい処理が要るわりに、スクショの注釈では短い言葉がほとんどなので、文字に合わせる方式にした
- 白地に色の枠線と文字の吹き出し。塗りと白い文字の方が、どの画像の上でも目立つ

## 見直す条件

- 長い説明を吹き出しに入れたい、という声が続いたとき(折り返しの方式を足す)
