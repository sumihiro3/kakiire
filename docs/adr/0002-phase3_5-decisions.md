# Kakiire フェーズ3.5の方針:線の種類、スタイルボタン、スクリーンショット、多言語化

## 決定

| 項目 | 決定 |
|---|---|
| 線の種類の保存 | `style.dash`(`dashed` / `dotted` / `dashDot`)。実線は書かない。`formatVersion` は 1 のまま |
| 先細り矢印の破線 | 塗りの形は破線にできないので、破線のときは「破線の軸 + 実線の開いた矢じり」で描く。軸は矢じりの付け根で止める |
| 破線の間隔 | 線幅の倍数(破線 3w:2w、点線は丸い端で 0:2w、一点鎖線 4w:1.5w:0:1.5w)。太さを変えても見た目の比率が変わらない |
| スタイルボタン | 色の隣のボタンを、今のツール・選択中の注釈に合わせて「太さ / 文字の大きさ9段+袋文字 / モザイク・ぼかしの強さ3段」に切り替える。線の種類は別のボタン |
| 文字の大きさのショートカット | ⌥⌘+ / ⌥⌘-(⌘+ / ⌘- は拡大・縮小に使っているため) |
| スクリーンショット | OS 標準の `screencapture -i` を Sandbox の中から起動する。撮る間は Kakiire を隠す。画面収録の許可がなければ撮らずにシステム設定へ案内する |
| 起動画面 | 文書に「画像なし」の状態は作らず、編集画面と同じ見た目の空のウインドウを出す。取り込んだら同じ位置・大きさで編集ウインドウに切り替える |
| 多言語化 | 日本語(開発言語)と英語。App だけが文言を持ち、String Catalog に日本語をキーとして英訳を付ける。Core / IO は表示名・エラー文を持たない(IO のエラーは英語の素の文で、表示時に App が訳す) |
| 既定のレイヤー名 | 作ったときの言語で文書に保存する(開き直しても訳し直さない)。番号は種類(`kindKey`)で数える |

## 理由

- dash を省略可能にしたので、古い文書はそのまま実線として読める。逆に 0.1.0 の Kakiire で新しい文書を開いて保存すると dash は消える(既知の型の未知フィールドは保持しない)。実害は線が実線に戻るだけなので、版は上げない
- `screencapture` は範囲選択・Space でのウインドウ選択・Esc での取り消しが OS 標準のまま使え、ScreenCaptureKit で範囲選択の画面を自作するより小さい。Sandbox から起動でき、画面収録の許可(TCC)は Kakiire に付く(ログで確認)
- ad-hoc 署名はビルドのたびに署名が変わる。画面収録の許可が外れることがあるので、根本対応はフェーズ4の Developer ID 署名で行う
- Core を UI 非依存に保つ(層の約束)。Swift Package の資源にカタログを入れると `swift test` の扱いが変わるので、訳は App に寄せた
